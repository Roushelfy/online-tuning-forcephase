## 1. 问题与动作

对每个实例先做一次**有界观察**，然后只从下面三个动作中**选择一次**，从头运行正式求解。观察可以包含多个临时试跑臂；试跑臂的状态不会续用到正式求解。

| 动作 | 正式求解参数（`build/fpc`，与 v4 相同） |
| --- | --- |
| D | `--phase=1 --forcephase=0` |
| F+ | `--phase=1 --forcephase=1` |
| F− | `--phase=0 --forcephase=1` |

- **正式求解的运行政策**：`--lrat=1 --fpc=1`、seed 0、T = 300 CPU 秒、16,000 MB、绑定一个物理核，与 v4 完全一样。dev 上已有的 401 × 3 次固定运行直接作为正式求解结果。
- forcephase 会同时关闭 rephase，比较的是配置包。I− 不是动作。
- 局部搜索和传播得到的都只是特征，**不是答案**：即使局部搜索找到满足赋值，也不输出，只记为特征 `g_found_model`。

**缺失与回退**（预先固定）：
- 若包需要的任何 obsprofile 段状态不是 `ok`，wrapper 直接选 D。不是 `ok` 的情况包括：
  - `cap`：超过本段上限；
  - `n/a`：根传播已经冲突；
  - `skipped`：总上限已到。
  这时已经花掉的观察 CPU 照常计费。
- 若静态部分超过包的静态上限，同样直接选 D。
- 试跑臂没有进入搜索、没有 final 记录或字段缺失时，特征记为缺失，并附带缺失指示变量。缺失从不填成 0；只有读出器在训练折内用中位数填补。

**试跑臂特征**：由 `scripts/observations_v5/obsfeat.py` 计算。这段代码在采集 dev 之前与本协议一起或紧随其后提交；任何特征—结果分析之前冻结，之后不再改定义。

- **每个臂各自的特征**：
  - 规模与速度：log 冲突数、log 决策数、log 传播数、冲突/秒、决策/冲突、传播/决策；
  - 学习：固定变量比例、学习单元与二元子句 / 千冲突、平均 glue、glue ≤ 2 比例、学习子句平均长度；
  - 当前状态：trail、best 和 target 赋值比例（x_trail/best/target_frac）；
  - 机制：stable 比例、rephase 次数；
  - 时间：解析时间占比与搜索时间占比（来自 CaDiCaL 的 profiling 段）；
  - 是否进入搜索。
- **E05 差值**：对上述每个指标，计算 F+−D、F−−D、F+−F−（计数类在 log 尺度上取差）。
- **R05 的 F 类特征**：
  - 相位与赋值：window 平均 saved 翻转率（只用比较样本数 ≥ 32 的 window）；自由决策负向比例；非根传播与根级的正向比例；
  - saved/target：两者的分歧率、target 已定义比例与负向比例；
  - 学习：学习子句正文字比例，以及它与传播正向比例的差；
  - 回退：chrono 回退比例，以及 chrono 与非 chrono 之间 glue 和正文字比例的差；
  - 趋势（F11）：后半 window 与前半 window 在负决策比例、glue、trail、best 上的差值，以及负决策比例在各 window 间的标准差；
  - 可用性（F12）：是否进入 stable、是否 rephase 过、是否有 target、window 数。

## 5. 成本与离线模拟

记 t_a 为动作 a 的完整正式运行 CPU；未解出时为 ∞。包 P 在实例 i 上的观察 CPU 为：

> o = obsprofile 所需段（解析 + 各段）的 CPU + 已运行的臂 CPU 之和 + κ_P

- **κ_P** 是 wrapper 的 Python 开销。它在 V1 中、模型拟合之前，在工程面板上用只观察不求解的真实 wrapper 测量：取（wrapper 总 CPU − 工具与臂的 CPU）的中位数。R00 沿用 v4 的 κ = 0.08。
- **若某个臂在其预算内答出并通过独立验证**：成本为截至该臂的观察 CPU，算作解出，后面的臂不再运行。
- **否则选动作 a**：若 a 解出且 o + t_a ≤ T − 0.1（v4 的 RESERVE），成本为 o + t_a；否则为 PAR2 = 600。
- **默认基线**是“不观察、始终 D”，即 dev 上 PAR2 382.10。所有净收益都相对它计算，所以观察开销已经包含在内，不再重复扣除。

## 6. 读出器与比较

**预处理**（只在训练折内拟合）：
- 中位数填补；对训练折中有缺失的列加缺失指示；去掉常数列。
- ridge 使用标准化后的特征，并截断到 ±5。

**学习目标**：对 a ∈ {F+, F−}，y_a = C_D − C_a（秒），其中 C 为第 5 节的模拟成本矩阵。目标已经包含超时和观察成本，是绝对 regret（M02），不是 log 倍数。

**新读出器**（每个包两种，R00–R11 共 24 个登记比较）：

1. **RG（ridge + 默认回退门）**：
   - 对两个动作分别拟合 Ridge(α) 预测 y_a。
   - 令 ŷ* = max(ŷ_F+, ŷ_F−)，只在 ŷ* > θ 时偏离到对应动作，否则保留 D（M01、M03、M04）。
   - α ∈ {1, 10, 100}；θ ∈ {0, 2, 5, 10, 20, 50, 100, ∞} 秒。
2. **TG（浅回归树 + 同样的门）**：
   - 对两个动作分别拟合 DecisionTreeRegressor，深度 ∈ {1, 2}，min_samples_leaf = 20。
   - 门和 θ 网格与 RG 相同。

超参数（α 或深度，以及 θ）在外层训练部分上用内层 3 折选择，准则是内层 OOF 平均净收益（C_D − C_选择）最大。平手时取较大的 θ，再取较大的 α 或较小的深度，即更保守的一方。

**R11（M10）**：
- 第一阶段用 R10 的静态部分，读出器与本行相同（RG 或 TG）。
- ŷ* > θ1 时直接偏离；否则若 ŷ* > θ_ask，追加 R06 的三个臂，由在“静态 + R06”上训练的同类读出器决定；其余实例保留 D。
- θ1 ∈ {20, 50, ∞}，θ_ask ∈ {−20, −5, 0}，第二阶段的 θ 用同一网格，全部由内层折选择。

**对照**（不计入 24 个登记比较）：
- 不观察、始终 D；
- v4 的静态流程与 0.1 s 试跑流程，按外层折重拟合，应当精确复现 v4 的交叉验证；
- v4 的旧读出器（logistic C = 0.1 加 log 倍数权重；成本树 tree1 / tree3）用在**每个包的同一输入**上；
- 事后最优（不可部署）。

**更强读出器**（M06，至多 3 个包，总登记比较 ≤ 27）：
- RF-gate：两个动作各一个 RandomForestRegressor（300 棵树，min_samples_leaf 10，max_features 0.33，random_state 20261023），门的 θ 网格与上面相同。
- 晋级规则：R01–R11 中，按 RG/TG 两者较好的外层 OOF 净收益取前 3 个包。这一步使用了外层结果，所以 RF 的数字偏乐观，只能当作开发证据。

## 7. 评分与断言规则

**每个比较报告**：
- 外层 OOF 的 mean PAR2 与解出数；
- 相对始终 D 的净收益（秒/题与 %），以及家族组 cluster bootstrap 95% 区间（10,000 次，seed 20261023）；
- 偏离到 F+ 和 F− 的题数，偏离的精度（偏离后比 D 更好的比例）；
- 错误偏离的总损失；
- 严重回退：D 在截止前解出而选择超时，或单题损失 ≥ 100 s；
- 收益集中度：前 10 题占正收益的份额；
- 平均观察 CPU。

**还要给出**：
- 默认回退曲线：其余超参数固定，扫描 θ，画收益、偏离率与回退率；
- 按 OOD 距离（H04，训练折 S28 标准化空间的 5 近邻平均距离）三分位的收益分解。

**断言规则**：
- 只有当“包 P + 读出器 R”相对“S28 + 同一读出器 R”的**配对**差的 95% 区间不含 0 时，才说**新观测有用**。
- 只有当新读出器在**同一输入**上相对旧读出器的配对差的 95% 区间不含 0 时，才说**决策方式改善**。
- 其余一律写“未显示”。
- 登记比较共有 ≤ 27 个，不做多重比较校正：单个区间不含 0 可能是偶然，必须看 V3 的实测与确认。
- 若一个模型在所有折上都回退 D，记为“退化为默认基线”，不算识别成功。

**特征筛查**（OBSERVATION_SCREEN.md）：
- 对每个新特征报告：定义、实际 CPU、缺失率、各优势组中位数、与 log2(C_F±/C_D) 的 Spearman ρ（总体、家族内去均值、家族 cluster bootstrap 区间），以及 Benjamini–Hochberg q 值。
- 比较次数如实披露。单变量弱不等于没用，单变量强也不等于可部署。

## 9. V3 部署与确认
