# Agent Goal v5：寻找能识别三种flag优势实例的新观测

设定日期：2026-10-23（美东）。依据用户要求，在已完成的v4基础上扩大识别/观察方式。当前范围仍是：先低成本观察，再从D、F+、F−中选择一次。不是回到正式搜索中反复切换。v4 goal完整存档于 [AGENT_GOAL_THREE_WAY_V4.md](AGENT_GOAL_THREE_WAY_V4.md)，v3动态目标仅作历史。

## 1. 起点与本阶段问题

先阅读 [v4最终报告](../reports/three_way/FINAL_REPORT.md)、[优势组](../reports/three_way/BASELINE_PROFILE.md)、[选择器比较](../reports/three_way/SELECTOR_CV.md)、[源码审计](SOURCE_AUDIT.md) 和 [观测候选库v5](OBSERVATION_CATALOG_V5.md)。不能把“廉价观测无效”扩展为所有观察方法都无效。

已确认：五年代表性面板500题（2022–2026各100），dev401、旧test99。v4上D整体最好，但dev里F+优势38题、F−优势24题，存在值得识别的子群。先前28静态特征、24个D短试跑特征和12个简单候选没有带来总体收益。v5重点检验：是否遗漏了方向不对称、真实残余结构、三动作相对反应、相位记忆和模型密度等信息；以及已有信息是否被错误的损失函数/过于激进的选择消耗掉。

## 2. 广泛候选库与首批优先项

候选库列出80项观测、12类选择方法，每项有定义、价值假说、成本、已试/新增状态与边界。它是广泛研究路线，不是80×12的全量组合任务。先实施最有希望且可廉价共享的指标，再由证据决定扩展。

首批重点：

1. **三动作相对探测**：D/F+/F−各做同预算短试跑，比较学习、传播、最大无冲突赋值和停滞的差；再比较同冲突工作量。不要只继续观察D的一条轨迹。
2. **双边传播与浅前瞻**：对同一抽样变量在根背景分别假设正/负，比较传播、失败文字和残余缩短；测量方向反应，不先假定“更多传播”代表更好。
3. **原式与真实搜索残余式**：先识别哪些变量/极性在预处理中消失或反转，再比较两者的结构特征；审计内部变量与原变量的映射。
4. **短子句/关键变量加权极性**：用JW式长度权重、二元蕴含图、AMO/EO等候选结构，检验全局文字比例是否被辅助编码稀释。
5. **正确的相位记忆和轨迹**：修复且核对saved翻转，区分决策/传播、saved/target分歧、回退条件与窗口趋势，记录缺失。旧坏特征不得复活。
6. **局部搜索和近优赋值偏置**：有限对比全0/全1/随机起点，观察残余违例、近优密度与一致性；近优未满足赋值不是模型，局部搜索不作为正式第四个动作。
7. **保守选择和绝对损失**：以相对D的实际PAR2净收益/严重回退为目标，证据不足保留D。只有比同输入旧模型更好，才可说决策方式改善；只有加观测后有增量，才可说新观测有用。

图社区、带符号WL、经验稳定变量、BP/LP和小型神经表征等均在候选库中。先完成A–F的关键观察；G局部搜索作为重要第二批，昂贵H07/H08不作完成前提。不能把未知/未实施写成已经否定。

## 3. 执行顺序

### V0：先校准旧结论和观测覆盖

- 核对旧28+24指标与实际代码，登记哪些已试、哪些只是换名。按0.1/0.5/2秒统计进入搜索、拥有有效checkpoint/target/restart的比例及缺失分布；区分预算太短与信号无效。
- 重算两种旧选择器的逐题收益/损失，分开正确偏离D、错误偏离D、从解出变超时、微秒级倍数与百秒级损失。旧logistic的log成本比权重与真实绝对regret不等价；旧成本树已直接用成本，不能宣称成本敏感从未做过。
- 单seed优势组的小样本只作探索标签。可在预先选出的开发小面板上做有限重复，检查优势方向与计时鲁棒性；不得按重复结果删掉困难/不利题，也不得将seed当新题。
- 在新实验前提交 docs/OBSERVATION_PROTOCOL_V5.md、观察注册表和预算，注明已经接触v4全部结果。

### V1：先获得有质量的新观测

- 保留原五年500题面板和分组，不重新抽一批更容易获胜的题。默认只用原dev401题进行方法开发，旧test99在v5已是曝光数据。
- 用固定seed20261023预选96个dev工程面板，按年份/家族/规模覆盖，不按赢家/收益选样。它只用于覆盖、开销和正确性检查；按优势组挑的额外案例只能标为诊断。
- 首轮按候选库R00–R11实施/登记。至少覆盖A/B/C/D/E/F六类并得到不少于24项真正新增或实质增强的指标；同一指标的多个分位数不能充作多种新方法。工程上不可行者给出证据及同成本替代，不无限修一个昂贵工具。
- 先测语义、可用率和成本，再将可承受的观察包扩展到dev401。原始探测记录保留，不只保存最终均值。样本无事件、观测超时和软件错误分别记录；字段缺失不能暗中变成有利的0。
- 仅需观测的最小hook可用于临时probe；先验证控制器关闭/观察开关不改变应相同的确定性搜索。正式三个动作尽量沿用已验证二进制，probe构建、标签构建、版本与成本语义分别记清。新探测字段不能用旧终局日志的未来内容回填。
- BCP/前瞻在隔离临时状态执行并撤销；不得把同一个动作运行后的状态冒作另一动作的相同根状态。多动作probe都从同一输入按声明的政策独立开始即可，不要求新建fork/COW系统。

### V2：识别增量价值，避免把全部问题强迫分类

- 先使用固定的家族分组外层5折、内层3折。归一化、缺失处理、特征筛选、聚类、门槛与观测预算全部只在训练/内层确定。v5是看过v4后的开发研究，即便有外折也不能改称全新预注册盲测。
- 首轮最多24项预列出的“观察包×读出器”比较：R00–R11各配①正则化动作成本差回归＋默认回退门；②浅成本树＋默认回退门。门槛网格、树深等小网格在协议中固定，实际拟合次数和所有结果完整保存。更强读出器只对开发中预定晋级的至多3个包比较，总比较数上限36，不做无界超参搜索。
- 用同样外折比较：不观察始终D、冻结的v4静态/试跑选择流程、相同新输入的旧读出器、新读出器、以及对应观察包。旧冻结全dev模型不能直接用于dev OOF，必须在每个训练折重拟合相同流程。
- 若增加G或昂贵H类，先提交下一小批观察包，说明上一批缺什么信息及预算。不能仅因某个单变量ρ低就排除交互，也不能凭最高相关性挑赢家。
- 优先报告偏离D的实际净收益、F+/F−选中精度与支持量、错误偏离成本、严重回退和收益集中度；PAR2/solved为主，分类准确率/AUC只作辅助。
- all-timeout的终端PAR2不提供真赢家标签，但它们仍在总体评分与观察成本里。接近组保留多种近优动作；不能为三类均衡丢弃D优势或超时题。
- 只选至多两个主要策略进入真实部署验证。若一个模型全部回退D，记录退化为默认基线，不能称识别成功。新方法不要求必须正收益，但必须对覆盖、识别错误和成本给出可解释证据。

### V3：真实部署与有限确认

- 先在dev上用外层未见该家族的模型真实运行最终wrapper，计入所有进程CPU，确认离线评分不是计时/预算假象。只需主要策略和必要配对，不重跑全部80项长求解。
- 如有未接触的新实例，先固定不超过80题的小确认集，保留2022–2026主赛道来源和家族/规模记录；优先未曝光家族，并给出实际覆盖。与全部已使用题/变体做hash、isohash和家族核对，不按新方法胜负选题。
- 冻结特征、代码、模型、观察上限和分析后，最多运行三固定动作加两个主要wrapper。默认一个固定seed，有限重复若需要须在解封前固定并计入预算。
- 旧test99只能作为清楚标注的历史/探索对照，不能再挑候选、调阈值或声称新的独立确认。若找不到足够独立的新数据，仍交付完整开发与真实部署证据，明确尚未独立确认，不无限收集数据。

## 4. 成本、预算、正确性和解释

- 单题总预算T=300 CPU秒，完整wrapper包括读取/扫描、图结构、BCP、每个临时试跑、推理、重新读入和正式求解；只给正式求解剩余预算。多probe的CPU相加，不能假装并行免费。观察计划默认总硬上限6 CPU秒；廉价特征可提前停止并用D，原式很大时解析也算成本。
- 试跑臂预算包括它自己的启动/解析/简化；外层wrapper开销另外计入整个观测。到达固定冲突数不获得额外免费预处理时间。缺失/未到检查点时如何回退须预定。
- 在T内解出且独立验证通过记总CPU，否则PAR2=600。checker CPU另计总账；probe提前解出同样验证。传播局部冲突、LP/BP、候选赋值都不得作为未验证答案。
- v4+本次后续新增计算累计上限仍为200 CPU核时；v4账本已用39.90，暂余最多160.10。先核实是否有其它新增消耗。模型拟合、图提取、校验、重复、失败和重跑也记账，不购买算力，不将“候选库很大”解释成无限预算。
- 建议控制V0/V1工程与小面板≤20核时、V2采集/模型/开发部署≤90核时、有限确认与校验≤50核时；精确计划须按实际运行数重算，不以分配上限当必须耗尽的配额。
- 全局换号、变量重排和变体始终同组；不能要求真实时间严格对称。部署输入不能用年份、家族名、实例ID、已知SAT/UNSAT、未来统计或终局模型。
- 特征探索的多重比较、组内相关、支持样本与区间必须披露。结论分为“已知旧结果”“新实测”“相关性”“机制假说”“未实施”；可靠负结果也可完成，不能宣称证明所有识别方式不可能。
