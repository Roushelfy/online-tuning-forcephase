## 1. 语义（R0）

1. **预求解答案直接采用**：probe 在 τ 内给出答案时，它的输出与证明就是最终答案，经独立检查后返回，不重复求解。
2. **未解时从头重跑**：probe 没有答案时，它被终止，所选动作在原始输入上从头运行。选 D 也一样，重复的工作照样计费。续用原 D 进程的版本不在本轮部署；若以后做，单独命名、计时和验证。
3. **τ 的计时**：τ 是 probe 进程（正式 D 命令）自己的 CPU，从进程启动算起，含解析与预处理。到达 τ 时发 SIGTERM，1 s 后仍未退出则发 SIGKILL。实际停止 CPU、超调量、退出码和 probe 的遥测都记录。完整 wrapper（Python、probe、选择、最终求解）由调用方用 wait4 计全部进程树 CPU。
4. **在线输入只有 CNF 本身和 probe 在停止前写出的遥测**：
   - 内容门只用停止前最后一个 `checkpoint` 记录，不用终局记录或之后的统计；
   - probe 在 τ 内一个 checkpoint 都没写出，记为缺失，取该策略事先确定的缺失动作；
   - SAT/UNSAT、模型、实例 ID、seed、来源、类型名都不作为在线输入，SAT/UNSAT 只用于事后分析。
5. **实现**：`scripts/online_selection_v9/presolve.py`；运行器为 `scripts/online_selection_v9/runner.py`，方法有 D / F+ / F−、机制配置、W（冻结策略）和 PROBE（只做 probe 的开发测量）。

### 2.2 试采样（48 道基础题，独立 seed）

- seed = 9000000 + 1000·轮次 + 100·类型序号 + 10·格序号 + 副本号。类型序号：rand3 0、col3 1、assign2 2、assign0 3；规模序号：S 0、M 1、L 2。

- 成本 c = 三个动作 CPU 的平均。目标与区间同 v8：S 2 s ∈ [1, 5]，M 10 s ∈ [5, 30]，L 40 s ∈ [30, 120]。不要求每题都落在区间内。

- **assign2 结构**：第 1 轮 3 个结构 × T ∈ {100, 200} × 2 题，共 12 题。逐级比较：
  1. 4 题中 c ∈ [1, 600] s 且 D 冲突数 ≥ 10⁴ 的题数，多者优先；
  2. 4 题中同时有 SAT 和 UNSAT 者优先；
  3. 中位 log c 更接近 log 10 者优先；
  4. 按 A、B、C 的顺序。
- **assign2 尺度**：
  - 用所选结构第 1 轮两个 T 的中位 c 求 log c 对 log T 的斜率，预测 c = 2 / 10 / 40 s 的 T，取最近的网格点，并严格递增；斜率不为正时取 T = 150 / 250 / 400。

## 4. 候选与选择（R2）

**开发成本模型**：对开发题 i 和 τ，记 PROBE 实测的 wrapper 进程树 CPU 为 q_i(τ)。

- probe 解出时，成本 = q_i(τ)；
- 未解时，成本 = q_i(τ) + t_a(i)，t_a 取 S1 中同一命令的完整 CPU（同一搜索，确定性）；
- REF 的实测检验这个拼接的误差，结果写入 PRE_SOLVE.md。

**A，时间门**：P(τ, a)，τ 取 7 个值，a ∈ {F+, F−}，共 14 个组合。

- 另报“始终 D”和三个固定动作；
- “D 先 2 s，未解再 F+”作为固定参照，无论开发结果如何都完整报告。

**B，内容门**：在同样的 probe 之后，用停止前最后一个 checkpoint 的 12 个指标在 {D, F+, F−} 中选一个，从头运行。

- 指标：
  - 规模：s_log_vars、s_log_clauses、s_cv_ratio；
  - 结构：s_bin_frac、s_pos_frac；
  - 前缀进展：r_log_conflicts、c_dec_per_conf、c_props_per_dec、c_glue_mean、x_trail_frac、x_best_frac、x_saved_neg_frac。
- 缺失指标时，取训练折中“未解题上总 CPU 最小的常数动作”。
- 读出器只有两种：
  - **树**：深度 ≤ 2，阈值取训练折的 25/50/75% 分位，叶最少 5 题，叶内选总 CPU 最小的动作；相对常数动作的节省不超过 θ ∈ {0, 5, 20} s 时保持常数动作。
  - **岭回归**：对 a ∈ {F+, F−}，在未解训练题上回归 Δ_a = t_a − t_D（秒），α ∈ {1, 10, 100}；取 min{0, ŷ_F+, ŷ_F−}，只有 ŷ < −θ（θ ∈ {0, 5, 20}）时才偏离 D。
- 对照组：只用 3 个规模指标的 B_s。

**交叉验证**：

- 只用 270 道主开发题，对照题单独评估。
- 格内按分割哈希排名，外层折号 = 排名 mod 5（每折每格 6 题），内层折号 = 训练集内排名 mod 3。
- 所有选择都只在训练部分做：τ、后备动作、读出器、超参数、标准化、缺失动作，以及 SBS。
- 外层总 CPU 即该族的估计。

**主策略**（事先写定）：

1. B 的外层总量比 A 低至少 1% 时选 B；
2. 否则 A 比 SBS 低至少 1% 时选 A；
3. 否则主策略就是 SBS 这个固定动作。

选定后，在全部 270 道开发题上用内层 3 折选超参数并拟合、冻结。部署的 wrapper 为：主策略（若不是固定动作）和“D 2 s → F+”参照（若与主策略相同就只跑一次），最多两条。

**SBS** 只按开发集三个固定动作的总 CPU 选。

## 5. 留出验证（R3）

- **运行**：主策略冻结、打标签之后，在同一个 cpu-low 节点上把 270 + 15 道留出题 × {D, F+, F−, W_main, W_ref} 交错运行。全部完成并独立检查后才计算完整均值；未完成的保持 null，并列出缺口。

## 8. 机制消融（R4）

- **样本**：开发集中每格 6 题，在开发运行完成之后按事后答案分层：各取分割哈希排名靠前的 3 道 SAT 和 3 道 UNSAT，某种答案不足时用另一种补齐。共 54 题。
- **配置**（都来自源码 third_party/cadical 的选项语义）：

  | 配置 | 参数 | 含义 |
  |---|---|---|
  | D | phase 1，forcephase 0，rephase 1 | 原生默认 |
  | D_R0 | `--rephase=0` | 只关 rephase，saved / target 相位仍在 |
  | D_P0 | `--phase=0` | 默认机制，初始负相位 |
  | D_R0_P0 | `--phase=0 --rephase=0` | 初始负相位，rephase 关闭，但不强制方向 |
  | F+ | `--forcephase=1 --phase=1` | 每次决策都用初始相位，忽略 saved / target，并且 rephase 不生效（rephase.cpp） |
  | F− | `--forcephase=1 --phase=0` | 同上，初始负相位 |

- **对照关系**：
  - 关闭 rephase 的作用：D 对 D_R0，D_P0 对 D_R0_P0；
  - 强制覆盖 saved / target 的作用：D_R0 对 F+，D_R0_P0 对 F−；
  - 初始相位或编码极性的作用：D 对 D_P0，D_R0 对 D_R0_P0，F+ 对 F−。
- 同一批次，版本、seed、输入、证明、硬件一致。报告按类型 × 答案的配对中位 log2 时间比与符号计数。
- 这些配置只用于诊断，不作为部署动作。v8 关于“UNSAT 优势来自关闭 rephase”的说法，按本节结果纠正或保留。

## 12. 偏离与补充记录

试采样第 1 轮（36 题，`pilot_r1`）之后、任何第 2 轮运行之前写定：

1. **col3 的 L 档保留 v8 的 n = 550**，不按第 2.2 节的调整规则改动。
   - 第 1 轮 L 档 4 题的中位 c 为 5.4 s（6.55 / 0.48 / 10.5 / 4.26 s，3 道 SAT、1 道 UNSAT），略低于保留区间的下限 6 s。
   - 按规则调整会出错：用这些以 SAT 为主的中位数外推，会得到 n = 800；而取区间内最近的单点（M 档 n = 500 的一道 42.9 s UNSAT 题），又会让 L 排到 525，比 550 更容易，与中位数指示的方向相反。
   - 着色在阈值附近的成本是双峰的：SAT 题 0.5–10 s，UNSAT 题可达分钟级（v8 试采样中 n = 550 的一道 UNSAT 超过 168 s）。少量样本的中位数主要反映 SAT 题。
   - 目标第 4.1 节要求着色先保留 v8 尺度以便比较，所以保留 550。只看成本，不看赢家。
   - rand3 三档与 col3 的 S、M 档按规则保留 v8 参数：中位 c 分别为 2.6 / 5.1 / 219（含一道仍在运行的 ≥ 600 s 题）和 0.79 / 4.0 s。
2. **assign2 增加一轮结构校准**：
   - 原因：预注册的结构 A / B / C 在 T = 100、200 时都极易（c ≤ 0.23 s，D 冲突数 ≤ 1.2k）。A 全 SAT，B 全 UNSAT 且很快，C 有 SAT 也有 UNSAT 但同样很快。按第 2.2 节规则会选 C；但沿 log c 对 log T 外推，要到 T ≈ 1300 才达到 40 s，那时顺序计数器编码有百万级辅助变量，“只把 T 放大”正是目标要改掉的缺陷。冲突度 3.0 时全可满足，3.5 时很快不可满足，难区在两者之间。

     | 结构 | c | 容量 | 下限 |
     |---|---|---|---|
     | D | 3.15 | 至多 ceil(T/4) | 无 |
     | E | 3.3 | 至多 ceil(T/4) | 无 |
     | F | 3.1 | 双边：至多 ceil(T/4)，至少 floor(T/4) | 有 |

   - **第 2 轮（结构）**：D / E / F × T ∈ {250, 400} × 2 题，共 12 题，seed = 9002000 + 200 + 10·格 + 副本。
