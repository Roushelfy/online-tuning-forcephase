# 五年比赛题的代表性抽样计划（2022–2026）

日期：2026-10-22（美东）。状态：后续执行计划，尚未生成新面板或运行新实验。当前主任务见 [Agent Goal v4](AGENT_GOAL.md)：简单观察后，在 D、F+、F− 中做一次选择。

## 1. 来源和规模

- 范围：SAT Competition 2022、2023、2024、2025、2026 的 main track；不混入不同任务定义的 incremental、parallel 或 MaxSAT 赛道。
- 优先复用 GBD 的元数据库、家族信息和 CNF 下载接口，逐年与官方比赛名单核对。记录数据库快照时间、hash、来源 URL、许可与缺失项；不把现有 2023–2026 旧 manifest 当作已包含 2022。
- 默认每年约 100 题，五年最多 500 个不同实例。每年先 10–20 题做工程 smoke，计入开发子集而非另造确认集。不要求全量下载 CNF，可先查询全部候选的轻量元数据，再只下载入选题与冻结替补。
- “代表性”指在可获取、可运行的 main-track 候选中覆盖家族与规模，不声称小样本无偏代表所有 SAT 应用或所有比赛题。

## 2. 在看新策略结果之前固定抽样

1. 建立五年候选表：实例 hash、可用 isohash、完整参赛年份、GBD family/保守 family_group、变量数、子句数、解压字节数、下载地址和历史曝光状态。未知家族沿用作者分组并披露。
2. 先按 hash 去重；同 isohash/已知同源变体作为重复或同组处理，不能跨 split。为每个唯一实例记录一个配额归属年，默认最早出现年份；全部参赛年份仍保留用于覆盖报告。跨年重复不当作多个独立问题，无法填满某年时报告实际数量。
3. 统一资源上限在运行前固定。新面板不机械沿用旧研究的 ≤100 MB 限制；应按可用内存/磁盘保留可承受的大规模层。若仍需采用大小上限，明确排除数量和各年/各规模层损失，并把结论限定于该范围。
4. 每年先覆盖尽可能多的家族，再在家族内按规模层抽样。规模层用该年候选的 log(变量数)、log(子句数)/可用文件大小分位数定义，小/中/大三层；具体边界、主要规模指标和每层配额由脚本在新运行前冻结。
5. 当家族数不超过年度配额时，先给各家族一个名额，剩余额度按 sqrt(家族实例数) 分配；默认单家族不超过年度配额的 10%。若家族过多或硬上限使名额不可分配，按固定随机顺序覆盖家族，再披露缺口/未用配额，不为凑 100 题反复调整。每个家族内部先覆盖存在的规模层，再按层内固定 seed 随机抽样。
6. 默认抽样 seed `20261022`，稳定按 hash 排序后使用确定性抽样；固定整数配额的余数分配与 tie-break。提交主名单及各层预排替补，只有下载损坏、确实不可获取或违反预定资源条件才替换，理由留痕。不能因超时、某动作更差或结果不理想换题。

不使用本项目 D/F+/F− 的胜负、oracle gain、是否能解出或 SAT/UNSAT 答案来挑题。只有在来源齐全且协议事先指定时，才可将官方公开难度作辅助分布诊断；它不替代家族和规模覆盖。部署选择器也不使用家族/年份/答案标签。

## 3. 划分与已曝光数据

- 默认按 family_group 整组分配 train/val/test，实例比例约 60/20/20；在不拆家族的前提下尽量覆盖五年。目标是近似比例，不为精确人数拆分同族。
- 每个实例记录 `prior_exposure`，其家族记录 `family_prior_exposure`，涵盖旧 train/val/test/t2026 及所有已执行的变体和分析。旧 204 和 304 不是新独立测试。
- 优先把已接触数据用于开发，把未使用实例/家族留给测试；真实未接触的 family-disjoint 测试可有较少年度覆盖，逐年明确样本数，不为年度均衡伪造独立性。
- 如果未曝光数据不够，就完成有清楚标注的家族分组交叉验证/重新设计评估；不能将其包装为新的盲测，也不要求无限找新题。分组内所有重复、seed 和变体均同折。
- 主面板按近似均衡的年度设计报告 pooled 结果和逐年结果；年度归属唯一计数，交叉参赛覆盖另表。可附年度/家族加权敏感性分析，不能将设计性抽样的 pooled 分数直接称全竞赛总体均值。

## 4. 必须交付的抽样检查

输出 `reports/three_way/DATASET.md` 与 `results/three_way/manifest.csv`：逐年候选/入选/排除/替补数、独立实例总数、家族覆盖、规模分布、跨年去重、各 split 数量、历史曝光情况。提供一条固定 seed 重建命令和 manifest SHA-256。

完成抽样不等于完成实验。三种固定 flag、公式观察和短试跑选择器的效果仍需按 [当前 goal](AGENT_GOAL.md) 真实执行并计入所有成本。
