# Agent Goal v11：扩大题目范围，识别可迁移的结构与flag偏好

设定日期：2026-10-27（美东）。状态：**已完成（2026-10-28）**，报告见 [reports/broad_scope_v11/FINAL_REPORT.md](../reports/broad_scope_v11/FINAL_REPORT.md)，协议见 [BROAD_SCOPE_PROTOCOL_V11.md](BROAD_SCOPE_PROTOCOL_V11.md)。分支 research/forcephase-study。

## 1. 目标与已有证据

核心问题：**哪些SAT问题结构具有稳定的D/F+/F−偏好，这种偏好能否由CNF本身廉价识别，并用于未见实例、规模、编码和家族？**

扩大类型、编码和真实来源，不只是给v10的三类生成题增加seed。先建立广泛的三固定模式基线，再决定是否需要在线搜索和复杂模型。允许负结果，不只保留forcephase占优的类型。

v10已完成；目标完整存档：[AGENT_GOAL_CROSS_SCALE_V10.md](AGENT_GOAL_CROSS_SCALE_V10.md)，结果：[FINAL_REPORT](../reports/cross_scale_v10/FINAL_REPORT.md)。v10在270题确认集上主策略相对开发SBS节省18.5%，但一题贡献约63%的净收益；简单结构类型路由是主要解释。未知公开家族与比赛题尚无收益证据。三模式短试跑在开发比较中无增量，本轮不作为默认扩张方向。

任务仍是低成本观察后在D、F+、F−中选一次，不做正式求解中的反复切换。沿用固定CaDiCaL版本和动作语义。

## 2. 资源、计时与评价的硬约束

沿用 [RESOURCE_POLICY.md](RESOURCE_POLICY.md) 与 [run_timeout_policy.json](../configs/run_timeout_policy.json)：
- 每题每方法完整进程树最多3600 CPU秒；在线观察、推理、停止、重启和正式求解合计一个上限。
- 项目与阶段累计核时不限，不恢复200核时或任何“剩余预算”；所有实际成本持续记账。
- 同一冻结面板某方法全部完成并独立验证后，才报告完整算术平均CPU；存在超时或未验证则均值及依赖它的收益为null。
- 有超时面板报告已解数、配对新增/丢失、CPU解题曲线、删失状态；不把3600秒当完成时间，不自动启用PAR2。共同完成子集仅作有筛选偏差的次要描述。
- 证明生成计入方法CPU，检查器另列账本；检查器失败是未验证，不是正确完成，也不自动等同求解器答案错误。
- 历史数据与结论不覆盖；本轮改用新stage与run_id，不重复启动已超时极难题以等待其最终完成。

任何新v11求解前，提交 docs/BROAD_SCOPE_PROTOCOL_V11.md、configs/broad_scope_v11 下实际清单规则、阶段配置与 reports/broad_scope_v11/SOURCE_AUDIT.md。

登记问题家族、生成器/来源版本、可获得性与许可、参数、编码、抽样规则、难度校准、已曝光情况、基础实例组ID、确认/未知家族划分。生成器缺失时先验证来源；不可编造可下载来源或假定编码工具已有实现。

v4–v10、旧比赛面板、旧留出、外推全部为曝光数据，仅用于探索、代码复用和历史对照。审计v5/v6既有观测，不换名重复负结果。

正式运行前锁定方法族、有限网格、训练规则、所有费用、主次比较和偏离处理。阶段清单、规则分别在其约束的运行前commit/push。发现数据正确性问题时记录偏离、修复重跑，不静默删除不利题。

## 4. S1：范围扩张与难度校准

### 4.1 至少八类生成/可缩放问题

保留随机3-SAT、图着色、耦合分配作为桥接，再增加至少五类：
1. 基数/伪布尔约束（单独的受约束可行性问题；不只把一种编码电路当新语义家族）；
2. 调度（与原分配生成器独立，包含时间/先后/资源约束）；
3. 规划（有状态转移与目标，而不只是任务分配）；
4. 位向量/电路类（例如可复现的小型算术电路、等价性或有界验证）；
5. 组合数学/图结构的另一家族（如匹配、Ramsey、鸽巢或其他有清楚可缩放定义的实例）。

这是来源选择目标，不代表具体工具已核实可用。对只产生易题、只有固定答案或特殊proof结构的生成器注明限制。可替换确实不可获得或无法正确生成的家族，但运行前写明原因，不能因F±不占优替换。SAT/UNSAT不要求强行均衡；预先定义生成任务，报告实际答案比例。

每家族三档规模，先从小范围探索成本。独立pilot每家族每档4题，共约96题，只跑D作校准；预先定义有限参数网格，依据成本和真实搜索覆盖调尺度，不能看F±胜率再选参数。保留少量亚秒对照与困难压力题，主要开发覆盖约1–300 CPU秒；3600秒是截止，不是目标难度。无法在某家族得到中等难度时披露，不用大量亚秒题冒充覆盖。

### 4.2 广泛观察面板与新的确认集

- 广泛观察/发现面板：8家族×3规模×12基础题 = 288题，每题三模式真实运行。全部视为开发数据。
- 新开发面板：每家族30题（每规模10），共240题；与发现面板去重。可与发现数据合并训练，但须预先明确训练池和分组。
- 新同家族确认面板：同样240题，每家族每规模10题，seed/基础问题独立；标签由运行管理隔离，规则冻结前不分析。
- 不因发现面板上的赢家、oracle空间或答案重新分配正式样本量；所有家族保留。若后续按信息价值扩样，作为单独探索阶段，使用预先固定的对称规则并披露，不改变确认集。
- 三模式先跑发现与开发，确认集在规则冻结后才跑。不能以“先看所有题三模式再建模”的方式泄漏新确认标签。

### 4.3 真实公开数据与完全未见家族

新增至少120道公开实际/应用实例，来自至少六个来源家族，覆盖不同规模；至少60道来自近五个可用比赛年份，每年约12道（年份以核实的实际公开发布为准，不杜撰未来/缺失赛事）。其余优先公开应用/验证/规划/调度等数据，而不只经典SATLIB小题。

至少四个公开来源家族在本轮发现与训练中完全不出现；完整名单、家族关联、跨年重复和旧曝光在运行前审计。无法保证未知家族独立时称“已见来源新实例”，不冒称跨家族。

按来源、规模和固定hash抽样，先独立pilot检验难度，正式清单冻结后不删超时题。原v10外部集D在1秒内解107/118，因此新外部集应明确报告<1秒、1–300秒、>300秒和超时的覆盖；若来源仍全部极快或极难，明确研究限制而非宣称已充分测试迁移。

真实外部集不参与阈值和模型选择。已曝光题可作为另列压力集，不能挤占新盲测名额。

## 5. S2：编码与符号控制

从发现/开发题中每家族预先选6个基础问题（共48），在支持至少两种合理CNF编码的家族上实施编码对照；再做全局文字翻转和变量重排。至少覆盖三类支持替代编码的语义家族，登记编码语义、版本和参数。某家族不支持时保留缺口，不用简单改变量名冒充编码变换。

- 每种编码运行D/F+/F−，保持其他选项一致，验证SAT/UNSAT等价；小实例必要时用独立枚举/参考解核实生成器。
- 全局翻转后F+/F−偏好可能交换，必须实测；不能据编码名直接决定动作。
- 同一基础问题的不同编码、seed扰动、变号或重排跟随同一个数据分组，绝不跨开发与确认。
- 对预先抽取的24题做少量solver seed重复，判断稳定偏好与单次重尾。重复不增加独立样本量。
- 说明偏好来自语义任务、规模、CNF编码还是偶然编号；相关性不直接称机制证明。
- 编码/扰动诊断若产生新规则，只用独立确认数据检验；确认集内部的变体不当独立样本计算区间。

## 6. S3：先建立结构与模式偏好的地图

交付 BASELINES.md 和 STRUCTURE_MAP.md：
- 每家族、每规模、每编码的三模式完成率、完整成本状态、明显得失、最大损失、收益集中度、oracle精确值或上下界。
- 微小计时差异不算稳定优势。沿用至少20%且至少1秒作为报告性明显优势阈值，不按此删题或硬造标签。
- 超时只能给可证实的成本下界/优势关系，未知不能当平局或完成值。
- 类型内与类型间的选择空间分开：整体oracle空间是否只是家族固定偏好？
- SAT/UNSAT只作事后分层，不能作为在线特征。
- 生成分布与真实公开分布分开；等量家族加权和按实例总CPU均披露，不事后挑权重夸大收益。

该基线阶段本身就是成果，即使找不到预测器也必须完成全范围报告，不能只保留F±获胜的子群。

## 7. S4：必要的新对照与有限方法比较

本轮主对照是**简单的结构识别后选固定flag**，用来判断复杂在线模型是否必要。

冻结前只在发现/开发池比较：
1. 固定D/F+/F−与开发集SBS；
2. 既有v10冻结策略直接迁移（不重训，作历史方法基线）；
3. 廉价静态结构规则：深度2/3树或少量可解释阈值，直接选D/F+/F−；不需要读取来源标签；
4. 结构类型识别→类型固定动作：类型分类器只读取CNF特征，动作由训练部分确定；明确未知/低置信输入回退D或训练SBS的预定规则；
5. 静态+一个短D前缀的保守成本读出器；
6. 与5匹配总观察成本、不读内容的预求解对照。

真实家族标签→家族最佳动作只能作事后诊断上界，不是可部署策略。不能将文件名、来源、题型名、seed、真实答案喂给选择器。

复用已实现廉价特征：规模、子句长度、二元/Horn、正负极性、变量度数、有限局部图结构。初始最多30个指标；图构造和分析有界。短D前缀只比较0.1/0.5/2秒，τ包含启动/解析，不免费延后到搜索开始。若未进入搜索，用预定的缺失/分布外回退，不能沿用在比赛题上盲目F−的失效方式而不检查。

不默认重开三臂probe大网格；v5/v10已有负结果。只有开发证据指向具体结构、明确新信息假说并预先登记一个小消融时才加，不改变主比较。

简单模型使用浅树或正则化动作成本差，有限网格与保守阈值；归一化、特征筛选、类型识别、SBS和阈值全部在训练折内。按基础问题分组做5外层/3内层验证，同时留一语义家族及留一规模诊断。删失训练规则预登记，不把3600秒当实际完成时间。

开发选择先比较已验证解题数，再在相同解题覆盖下比较明确命名的实际资源消耗；全部完成时按完整总CPU。用同一准则选SBS，不事后用确认集最佳固定模式冒充开发SBS。最终最多冻结一个主策略、一个最必要的简单结构对照；同时部署固定三动作和必要的匹配预求解对照。旧v10基线是否独立部署在协议中提前锁定，不看确认结果选对照。

## 8. S5：独立验证与成功标准

规则、特征、阈值、回退、主次比较和数据清单在确认/外部运行前冻结；新确认240题分三块各80题，八家族每块各10题，规模分配在全240题上平衡。不看第一块改后两块，不因出现正结果提前停。

- 先报告三固定模式、开发SBS、简单结构对照、主策略及匹配预求解对照。
- 全部完成的预定面板：主策略相对开发SBS实际减少至少5%，实例分组配对95%区间下界>0，才能称可靠收益；相对简单结构对照和匹配预求解对照的增量单独检验。
- 有超时面板：完整均值null，已解配对、置信区间与解题曲线是主要证据，不用只多解一题宣称可靠胜利。
- 预先指定SBS为主要比较，结构增量为次要比较，说明多重比较；逐家族/规模/编码报告损失，不能整体平均掩盖严重退化。
- 相对事后最佳固定模式单独报告，不能替代开发SBS或被遗漏。
- 收益集中度、去掉最大贡献题的敏感性仅为诊断，原主分数不删除该题；报告观察开销、严重误选和提前解出贡献。
- 未见公开家族与同家族新实例分开；模型不胜简单结构路由时，成果应明确为廉价结构识别有效，不称细粒度在线预测成功。
- 外部仍过易/过难、编码变化破坏优势或只有特定家族有效时，明确适用范围。
- 确认结果不能用于返调。新增假说另立下一轮确认。

## 9. 交付与执行顺序

新产物放 configs/broad_scope_v11、scripts/broad_scope_v11、results/broad_scope_v11、reports/broad_scope_v11；及时commit/push，不强推。

交付：
1. SOURCE_AUDIT.md：来源、家族、曝光、跨年/同构重复及可用性。
2. 协议、pilot与清单冻结记录、参数、生成/下载命令、分组校验和。
3. BASELINES.md：广泛三模式结果、超时状态、oracle界与得失集中度。
4. ENCODING.md：编码、变号、重排和重复对照。
5. STRUCTURE_MAP.md：哪些结构存在稳定偏好，哪些规律不可识别或不可迁移。
6. SELECTION.md：简单结构路由与在线模型的增量、开发验证与冻结依据。
7. VALIDATION.md：真实wrapper新确认和未知家族验证、全部开销与分层局限。
8. FINAL_REPORT.md：简明中英文结论、4–6张核心图、真实复现命令，区分实测/相关/假说/未知。
9. COMPUTE.md：全部实际成本和平台损失，累计不限。

执行顺序：来源与协议→独立pilot→清单冻结→发现/开发三模式广泛基线→编码与结构分析→有限方法验证与冻结→新确认及外部测试→报告。不得在只跑了旧三家族时宣布范围扩张完成。

本阶段的完成条件是：广泛覆盖、可信基线、对结构识别和在线模型增量的独立检验及清楚适用范围；不是一定得到正结果，也不是无止境扩张题目、模型或超时。
