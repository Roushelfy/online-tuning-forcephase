# Agent Goal v4：低成本观察后，在默认、强制正、强制负之间做一次选择

设定日期：2026-10-22（美东）。依据与老师交流后的课程要求重新收敛范围。本文是当前活动 goal，可全文交给执行 agent。旧目标保存在 [AGENT_GOAL_SWITCHING_V3.md](AGENT_GOAL_SWITCHING_V3.md)，仅作历史记录；旧动态切换门槛和里程碑不再支配本阶段。

## 1. 唯一主任务

对一个 SAT 实例先做低成本观察（公式分析或短时间试跑），然后从以下三个实际配置中选择一个完成求解：

| 动作 | CaDiCaL 参数 | 含义 |
| --- | --- | --- |
| D | 不加 phase/forcephase 参数；显式等价为 `--forcephase=0 --phase=1` | 固定版本的默认原生相位策略 |
| F+ | `--forcephase=1 --phase=1` | 持续强制正方向 |
| F− | `--forcephase=1 --phase=0` | 持续强制负方向 |

回答：什么廉价信息能帮助三选一？计入观察成本后，是否优于开发阶段选出的最佳固定动作？默认 CaDiCaL 含 saved/target/rephasing，不称为纯 phase saving；forcephase 的配置副作用属于所选择的实际策略包。I−（仅初始负）可复用作补充对照，不是第四个主动作。

首选外部 wrapper：读公式/短试跑 → 选择一次 → 用选定参数启动正式求解。不要求保留试跑状态，不需要新的内部控制补丁、同状态分叉、多次切换、bandit/RL 或大规模机制消融。既有动态控制成果保留为背景，不继续扩展该方向。LPN 属于可选补充案例，不是完成主任务的前置条件。

## 2. 数据：近五届，每年只取代表性的一部分

主数据范围为 **SAT Competition 2022、2023、2024、2025、2026 主赛道**。默认每年目标约 **100 题**，跨年去重后合计最多 **500 个独立实例**，不要求下载或运行全部比赛题。先用每年 10–20 题做工程 smoke，再执行固定面板；smoke 样本属于开发数据。

按 [FIVE_YEAR_SAMPLE_PLAN.md](FIVE_YEAR_SAMPLE_PLAN.md) 冻结抽样规则与 manifest：先覆盖题目家族，再兼顾规模层；按元数据抽样，不能按 D/F+/F− 谁获胜来筛题。跨年重复只计一次；记录全部参赛年份与唯一配额归属。资源限制和缺失的年份/家族必须披露，不默默用更多其它年份补齐。

旧 817 / 204 / 304 已有结果均属已接触证据。它们可以按新抽样规则复用，但不能把其中旧 test 或 t2026 再称为全新未见测试。默认按家族划分 train/val/test，约 60/20/20，并尽量平衡年份；新独立测试优先取未被旧研究接触过的实例与家族。若独立性不足，仍完成分组交叉验证和课程研究报告，明确“重新设计后的评估/泛化尚未独立确认”，不为独立确认无限扩大题库。

## 3. 最小实验流程

**S0：固定范围与清单。** 阅读 README、源码审计、旧最终报告，盘点已有代码和数据。继续固定 CaDiCaL `c60730422e758ef1cebe7aeddf2dda31c996bf04`。在运行新实验前提交抽样名单、分组/分折、参数、CPU/内存限制、特征、试跑预算、模型候选和成本规则，使用 `docs/THREE_WAY_PROTOCOL.md`。无需先完成旧 v3 全部工程任务；只修复阻塞本轮执行或正确性的问题。

**S1：三种固定配置与互补性。** 对选定开发面板运行/核验 D、F+、F−。旧记录只有在构建、公式、seed、cutoff、证明设置和计时语义一致时才能直接复用。输出三种基线的 PAR2、solved、家族/年份分布、各动作胜负和三动作 hindsight oracle。oracle 只表示该集合的事后潜力，不是可部署选择器；两项超时不代表真实完成时间相同。不因 F+ 总体较差而从主动作中删除它。

**S2：先做简单选择器。** 比较两类输入：①低成本公式统计，如变量/子句数、子句长度、正负文字比例、Horn 比例；②相同静态信息加一次固定默认 D 短试跑的统计，如冲突、决策、传播和近期学习子句统计。只使用决策之前的信息。先试人工阈值、深度不超过 3 的树、正则化三分类逻辑回归；以预测三动作成本/成本敏感选择为优先，不能只优化分类准确率。最多 12 组预先列出的候选/超参数组合，避免无界搜索。

短试跑默认只在 D 下进行，候选预算为 0.1、0.5、2 CPU 秒，具体预算只用开发数据选择；若引入有限预处理步骤也要计时。试跑提前解出且验证通过时直接返回答案，不重新求解。试跑没有解出时，只选择一次正式配置；不得先把三种都跑到终局再假装预测。未知 SAT/UNSAT、家族名、年份、实例 ID 和终局结果不作部署特征。旧失效 flip 特征不使用；正确实现它不是本轮必选项。

**S3：冻结并真实测试。** 只用 train/val 或家族分组嵌套交叉验证选择模型、特征和观察预算。冻结一个静态选择器、一个短试跑选择器，以及在 D/F+/F− 中按开发表现选出的最佳固定动作。对测试面板实际运行这两个 wrapper 和三个固定动作。测试后不调参、不换主候选。若只剩历史已曝光数据，按上节明确评估性质，不伪称新预注册独立确认。

**S4：完成课程研究交付。** 给出哪些观测有用/无用、哪些家族偏好哪种动作、选择错误的损失，以及观察成本是否吃掉收益。三种固定配置的结果、完整选择流程和总体表现是主体；机制实验与动态切换仅为历史补充。可靠负结果可以完成任务，不设置“必须加速 5%”的硬性成功门槛。

## 4. 统一计分、预算和验证

- 每实例统一总预算默认 T=300 CPU 秒。wrapper 总时间包括解析、特征、试跑、推理、重新读入与正式求解；正式求解只得到剩余预算。超时记 PAR2=600。基线采用同样硬件、内存与证明政策；模型/证明检查 CPU 另计总账。
- 训练标签可以来自开发数据上三种完整独立运行；这是“从头选配置”的标签，不是相同搜索状态 continuation 的标签。短试跑选择器的离线诊断需计入观察成本；最终收益必须用真实 wrapper 运行验证，不能直接套旧动态 replay 成本。
- 主结果报告 PAR2、solved、观察开销、各动作选中次数、严重回退、逐年与逐家族表现。给出相对最佳固定动作及 D 的配对差和家族重采样区间；分类准确率仅作辅助。SAT/UNSAT 只作事后分析。
- 默认固定一个 seed 开始，准确披露单 seed 的局限，不把同实例的置换当新问题。测试前若计划增加重复，先冻结相同的重复集合与预算，不挑有利 seed。
- 默认新计算上限 200 CPU 核时（含检查、失败和重跑）。500 题 × 3 固定动作 × 300 秒最坏 125 核时；约 100 题 × 2 wrapper × 300 秒最坏 16.7 核时，其余留给试跑、分析与验证。以实际 split 和资源重新核算，预算不足时预先缩减面板/候选，保持五年覆盖，不启动全量比赛矩阵。
- 所有报告 solved 均经独立模型或证明检查。结果可追溯版本、manifest、run_id、状态与实际命令；缺失/crash/OOM/wrong 与 timeout 分开，不能静默删除。保留旧冻结标签、报告与证据，不重写历史结论。
