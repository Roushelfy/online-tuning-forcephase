# Agent Goal v10：跨规模的低成本 D / F+ / F− 三选一

设定日期：2026-10-26（美东）。状态：执行中——S0（旧实验审计、协议、阶段计划）已在任何 v10 求解前提交，见 [CROSS_SCALE_PROTOCOL_V10.md](CROSS_SCALE_PROTOCOL_V10.md)、[PRIOR_AUDIT.md](../reports/cross_scale_v10/PRIOR_AUDIT.md)。分支 research/forcephase-study。

## 1. 核心目标与研究边界

通过廉价CNF分析或短试跑，在默认phase saving（D）、force positive（F+）、force negative（F−）中选择一次。重点回答：**能否提前识别强制方向会显著变差的实例，并在未参与开发的规模上稳定超过最佳固定模式？**

仍是课程要求的“观察后选flag”，不是正式搜索过程中反复动态切换。保留固定CaDiCaL版本与三动作语义。可以得到有边界的负结果，不要求为正结果无限调参。

当前资源政策：[RESOURCE_POLICY.md](RESOURCE_POLICY.md)、[run_timeout_policy.json](../configs/run_timeout_policy.json)。每题每方法完整求解进程树最多3600 CPU秒；在线方法的解析、分析、所有试跑、模型推理、停止/启动、重启和正式求解合计受同一个截止约束。累计项目与阶段核时不限；账本不是停止阈值。

v9目标完整存档：[AGENT_GOAL_ONLINE_SELECTION_V9.md](AGENT_GOAL_ONLINE_SELECTION_V9.md)。已有结果见 [VALIDATION](../reports/online_selection_v9/VALIDATION.md) 与 [TIMEOUT_3600](../reports/online_selection_v9/TIMEOUT_3600.md)。

## 2. 起点：已知什么、不知道什么

- v9新留出270题全部完成：D平均57.91秒，F+31.36秒（减少45.8%，95%区间30.4%–54.6%），F−34.54秒。固定参照D先2秒再F+为29.12秒，相对F+减少7.2%，区间−2.1%–20.7%，没有可靠额外收益。
- 规模外推90题的历史完整均值：D1225.9秒，F+1768.3秒，D2→F+1688.9秒；F+反而多耗44.2%。3600秒内D/F+/F−/参照分别解82/79/82/78题。优势有范围，不是普适规则。
- 最大分配规模上F+耗时约为D的4.36倍；着色仍有收益；随机SAT/UNSAT的事后分层有解释力，但答案不能充当在线输入。
- 旧55题在新截止下D42题、至少一个固定动作46题可解；F±另有14–15题只有旧300秒下界。不能把这些题当3600秒超时或完整标签。
- v5已经尝试过三动作配对短试跑、传播和结构指标；v6也做过观测稳定性检查。**三模式试跑不是首次提出。** 执行前逐项审计旧实现、信息窗口、成本、失败方式和可复用代码；本轮新增价值必须是跨规模设计、可识别的信号或真实部署收益。
- v9“早期前缀看不出SAT/UNSAT”只表示该批特征和模型没有成功，不是不可预测性证明。

协议需在运行前锁定：数据来源与生成器、pilot规则、规模、基础实例分组、重复/同构审计、开发/确认/外部划分、方法族、小网格、主次比较、选择准则、超时统计和偏离处理。

所有v9及以前数据（含原留出、外推与旧55题）均已曝光，只用于开发、探索或单独标记的历史再评价，不再称新盲测。

## 4. S1：新数据与三模式基线

### 核心规模设计

三生成类型继续使用随机3-SAT、图3着色、耦合分配；每类型设四档规模：三个开发范围档和一个更大外推档。目标规模先以v9及其外推参数为起点，不因哪种flag获胜来选择。

- 新开发270题：3类型×3范围内规模×30基础实例。
- 新同范围确认270题：同九格各30个独立实例。
- 新规模外推90题：每类型一个训练范围外规模×30个独立实例；不进入训练。
- 独立pilot最多72题：每类型四档每档6题，只核实生成正确性、真实搜索和成本覆盖。pilot可用默认成本校准尺度，不按F±胜率、真实答案或最终收益挑参数；调整规则在pilot前写明，正式清单冻结后不删难题。
- 目标覆盖亚秒、秒级、几十秒到分钟级。3600秒是最终截止，不是所有题的目标难度。

### 外部家族检查

另选120道公开非比赛实例，至少两个不在核心训练中的问题家族，按来源、规模元数据固定抽样。避免再用全部亚秒级经典题作为唯一外部证据。允许独立、非正式pilot评估难度，选择规则与去重结果提前公开；无法获得足量合适题时披露实际来源与覆盖，不重复凑数。

外部家族不参与模型或阈值选择，与核心结果分开报告；不能把生成分布胜利当成未知家族胜利。旧比赛题只作单独压力测试，不为已经超时的极难题放宽上限、反复重启或换seed。若要补齐旧F±的3600秒未知记录，先列清单和必要性，使用新stage保留历史。

### 分组与冻结

新基础seed、来源和输入均与旧数据去重。变号、重排、编码变体跟随同一基础问题分组。确认270题固定为H1/H2/H3各90题；全部规则在第一次确认运行前冻结，三个块一次执行，不看H1改H2，不因出现正结果提前停止。外推90题、外部120题也在看结果前冻结。禁止ID、文件名、来源标签、生成seed、类型名或答案作为在线输入；CNF自身可计算的结构允许。

三固定模式全部真实运行，答案独立验证。将运行超过截止、真实平台中断、未验证、错误和不可重建明确分开，旧300秒证据不自动变成新超时。

## 5. S2：先分析选择空间和误选代价

在旧数据与新开发集上计算：

- 各固定模式与SBS（开发集选出的最佳固定模式）的差异、逐题最大损失、收益集中度、类型/规模分层。
- 分清“明显优势”“接近”“因超时未知”。建议明显优势描述阈值为同时至少20%且至少1秒，阈值只用于报告，不删题、不硬编码训练标签；超时仅在下界足够时给出已证实优势。
- Oracle为事后最优参照，不是可部署结果；存在未知臂时报告可证明的界或null，不能把已完成臂最小值当精确oracle。
- 对开发集预先按类型和规模选54个基础实例（每格6个），做solver seed与变量重排诊断，记录赢家稳定性、总收益和严重损失稳定性。重复不算独立样本。
- SAT/UNSAT只作事后分析。研究目标是预期绝对CPU节省和避免严重误选，不是赢家分类准确率。

## 6. S3：三类观察与真实部署

最多登记以下三个主方法族，使用同一简单读出器和相同开发分组，逐级比较新增信息是否抵得过新增成本。

### A：廉价静态分析

优先复用v4/v9已有规模、长度、极性、二元/Horn比例、变量度数指标；适当加入约束图局部结构，但图分析必须有明确工作量/时间上限。先登记不超过20个可解释指标；归一化、缺失处理只用训练折。不能靠来源字符串辨识题型。

静态分析有界，超出观察上限就停止并回退，不让大公式提取特征耗尽正式求解时间。

### B：默认D短搜索

沿用静态指标，增加D前缀：传播/决策比、冲突与决策增长、学习子句质量、不同窗口进展。保留v9原12特征作为固定旧基线。只读取停止前实际发生的事件，缺失显式标记，不用终局日志填补。

窗口候选固定为0.1、0.5、2、5 CPU秒。时间窗内包含启动、解析和预处理；多窗口可从一次前缀中提取，但不得使用选择时刻之后的信息。

### C：D/F+/F−配对短试跑（优先检验）

每种模式的名义窗口候选固定为0.1、0.5、2 CPU秒；顺序串行运行，总成本约3τ加停止/启动开销，所有费用均计入。比较各臂单位CPU、单位冲突的前缀统计及差值/比例，不把“冲突少”直接当“最终更快”。进展对最终成本的预测力必须由开发验证确认。

试跑顺序取D→F+→F−和F+→F−→D两种，在内层开发中选择，不用每题已知最快动作决定顺序。任一试跑给出有效答案时直接返回并独立验证，不继续浪费后续probe。报告有多少收益来自提前解出而非选择准确。

全部probe未解后，选择一个动作并从头正式求解，即便选D也重新收费。与v9保持可比；续用/暂停恢复另立变体协议，不能偷偷免费复用。单线程串行是主实现，不通过三核并行制造墙钟优势而遗漏CPU。

### 必要对照与消融

固定D、F+、F−、开发SBS；固定D2→F+；静态A；单D前缀B；三模式前缀C。加入同总观察成本、只用时间/是否解出而不读取内容的对照，以及固定后备的三模式短调度，以区分“多试了几种模式”与“统计指标指导选择”的贡献。

观察开销和全部失败probe均进入每次方法成本；不能只报告离线拼接。离线模型可筛选候选，但最终结论必须来自冻结后的真实wrapper。

## 7. S4：保守读出器、分组验证与冻结

只使用深度2/3浅树或正则化的动作成本差模型。超时标签作为右删失/成本下界，不当作3600秒完成值；可用有证据的配对排序或适当生存损失，具体训练规则须在新开发结果前登记。审计模型是否仅学到规模/类型代理。

有限网格：岭正则0.1/1/10，树深2/3；保守门的最低预测节省阈值0/0.1/1秒。预算τ、读出器、阈值在内层选择，5外层×3内层按基础实例分组，分层保持格覆盖。另做留一规模档开发诊断；它不是独立外推成功。

所有方法选择与SBS采用同一预定开发准则：
- 有超时时优先已验证解题数，其次较低的实际方法CPU消耗（仅称有限截止的资源成本，不能称完整平均完成时间）。
- 面板全部完成时按完整总CPU。
- 只在性能相近时优先更低观察开销和更简单的策略。规则与并列容差运行前固定，不临时换准则挑模型。

至少比较B相对A、C相对B和相同成本的无内容对照。最终最多冻结一个主策略和一个有明确科学用途的固定参照；没有增量时可以冻结SBS作为负结果，不强迫选择复杂模型。所有缩放、特征选择、模型、阈值及SBS均在H1前冻结。

## 8. S5：独立验证与成功标准

固定3600秒，每题交错运行三固定模式与冻结策略，尽量同硬件、相近负载。求解和证明生成计入方法CPU；独立检查器另列研究账本。检查器失败不算已解。计时语义有变才增加必要受控子进程测试，不能用伪测试替代真实部署。

分别报告同范围270题、H1/H2/H3、规模外推90题、外部120题：
- 所有方法各自完整完成时，报告同固定面板算术平均CPU、总CPU及相对D和开发SBS的收益。主目标是相对SBS至少减少5%，配对95%区间下界大于0；以实例为重采样单位，按预定格分层。
- 有超时时完整均值及相应收益保持null；报告已解数量、配对新增/丢失题、预定时间点与解题曲线、逐题删失状态。不同已解数用配对分析与区间，不只看一题差值就宣称可靠胜利。
- 共同完成子集均值仅为有筛选偏差的次要描述。不启用PAR2主指标、不用3600秒伪装完成时间，也不删除最慢题。
- 报告观察的平均/分位开销、赢家分类仅作辅助、最大误选损失、前1/3/10个收益占比、类型/规模分层及事后答案。
- 同范围获益不能称跨规模成功：外推必须独立呈现相对D和SBS的方向、区间与集中退化；未知家族结论另列。如一类题存在可靠严重退化，明确限制适用范围，不以整体平均掩盖。
- 内容选择的收益须超过匹配总probe成本的无内容对照，否则只能称预求解/调度收益。

不看新确认结果返调模型。若后续产生新假说，使用新的独立确认集并标为下一轮，不重复使用本轮盲测。

2. 协议、pilot记录、冻结清单、去重/分组证据、生成命令与来源。

4. OBSERVATIONS.md：A/B/C全部登记尝试、覆盖、成本、前缀有效性与匹配成本消融。
5. SELECTION.md：嵌套分组验证、超时标签处理、保守门与冻结依据。
6. VALIDATION.md：真实wrapper独立测试、分块、规模与家族迁移、区间与超时状态。
7. FINAL_REPORT.md：清楚中英文结论和4–6张核心数据图，区分实测、离线模型、假说、未知；真实复现命令。
8. COMPUTE.md：全部求解、生成、观察、检查、失败、重跑的实际累计账本，只记账不设核时额度。

结束条件是完成登记比较与独立验证、解释有效范围及失败机制，不是一定得到正结果。若三模式probe在计入开销后无增量，交付清楚的负结果和证据；不通过无限增加特征、模型、观察时间来延长本阶段。
