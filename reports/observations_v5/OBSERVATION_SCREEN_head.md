# 观测筛查：新观测的定义、实际成本、缺失与信号

本报告覆盖首批 11 个观察包（R01–R11）在 dev 401 上的观测。每一项观测的定义、实现代码、所属包和状态都登记在 [registry.json](../../configs/observations_v5/registry.json) 中。

- **工程检查**：等价门、覆盖、开销、H01/H02 诊断见 [V1_ENGINEERING.md](V1_ENGINEERING.md)。
- **生成表格**：本文第 7 节附有 `scripts/observations_v5/v5screen.py` 生成的表，逐特征全表在 `results/observations_v5/screen.csv`。
- **适用范围**：所有结论都是 dev 上的描述，不是部署规则。

## 1. 实施范围

- **首批观测**：候选库 80 项中实施了 50 项，另有 1 项（C03）部分实施，按注册表的 A–G 类分组如下：
  - A（静态极性与约束几何）：10 项
  - B（单位传播与有界前瞻）：7 项
  - C（预处理与残余公式）：4 项
  - D（图结构、局部依赖与编码指纹）：7 项
  - E（直接比较三动作的短探测）：10 项
  - F（相位记忆与学习轨迹）：7 项
  - G（局部搜索与模型偏置）：5 项
- **诊断与分析**：H01、H02 用作诊断，H04 用于分析。
- **新特征数**：R01–R09 共 507 个新特征（不含 v4 的 28 个静态特征 S28）。R10、R11 是这些特征的组合包。
- **未实施**：26 项未实施，大多是 P2/P3 优先级，理由逐项写在注册表中。未实施不等于已否定。
- **满足 goal 的门槛**：goal 要求“覆盖 A–F 六类，且至少 24 项真正新增或实质增强的指标”。本轮实施的项目覆盖了 A–G 七类。

**两批采集**：
- 第一次采集暴露了两个工程缺陷：局部搜索段的上限没有给建表留余量；观察总上限没有执行。这两项在任何特征—结果分析之前修正，记在协议偏离记录第 1–2 项。
- 修正后全部重新采集。第一次采集的记录保留在数据目录，不再使用。
- 本报告和所有建模只用第二次采集。

## 2. 实际成本

数字来自 dev 401 的中位数；最坏情况都受观察包上限约束，详见 V1 第 2 节。

| 观察方式 | 实际 CPU |
| --- | --- |
| 解析加任一静态段 | 中位只有几毫秒，p90 在 0.03–0.6 s |
| 局部搜索段（三个起点各 0.2 s） | 中位 0.17 s |
| 三动作试跑 0.2 s / 0.5 s / 512 冲突 | 每题合计中位 0.69 / 1.59 / 0.21 s |
| D 2 s 臂 | 约 2.0 s |
| wrapper 自身（κ） | 0.032–0.042 s |

**观察不完整而强制回退 D 的题数**：
- 静态包为 7–12 题，都是几百 MB 的大公式；
- 试跑包为 0–2 题；
- R10/R11 有 10 题，它们的静态上限是 2 s。

**试跑在观察阶段直接答出的题数**：R05 为 28 题，0.5 s 三臂为 22 题。所有答案都通过独立检查。

## 3. 缺失与覆盖

- **静态包的缺失**：缺失率中位 0–0.3%。最高的几项属于“结构不存在”，而不是没观察到：
  - `a07_eo_dir` 缺失 74%：没有找到恰一约束（EO）组；
  - `c04_inverse_share` 缺失 55%：没有非平凡等价类；
  - `b01_fixed_pos_frac` 缺失 44%：根传播没有固定任何变量。
- **试跑包的缺失**主要来自“试跑臂还没进入搜索”：0.2 s 时有 24% 的题没有进入搜索，0.5 s 时为 13%，512 冲突的臂为 7%。
- **缺失的处理**：所有缺失都保留为缺失，并配有缺失指示变量，从不填 0。v4 的 0.1 s 试跑有 30% 的题没进入搜索，见 [COVERAGE_AND_ERRORS.md](COVERAGE_AND_ERRORS.md)。

## 4. 与优势方向的相关：仍然只有弱信号

在至少一个动作解出的 199 个 dev 实例上，计算每个新特征与 r_F+ = log2((C_F+ + 1)/(C_D + 1)) 和 r_F− 的 Spearman ρ，共 966 个检验。

- **强度**：最大 |ρ| = 0.29，与 v4 中“廉价特征 |ρ| ≤ 0.3”处在同一水平。
- **显著性**：按全部检验做 BH 校正后，没有一个 q < 0.05；q < 0.1 的只有 4 个。
- **一致的特征**：同时满足 |ρ| ≥ 0.1、家族内同号、cluster bootstrap 区间不含 0、q < 0.1 的也只有 4 个：

  | 特征 | 包 | 关联 | 方向 |
  | --- | --- | --- | --- |
  | `f10_chrono` | R05（D 试跑中 chrono 回退的比例） | r_F+，ρ = +0.29 | 越高 F+ 越慢 |
  | `c01_res_pure_frac` | R01（残余式中纯变量的比例） | r_F+，ρ = +0.25 | |
  | `e02_glue_dFm` | R06（0.2 s 时 F− 与 D 的平均 glue 之差） | r_F−，ρ = +0.29 | F− 学到的子句 glue 越高，F− 越慢 |
  | `ec_ldec_dFp` | R08（512 冲突时 F+ 与 D 的 log 决策数之差） | r_F−，ρ = −0.26 | |

  由于 q 的门槛是 0.1，这 4 个里预期有约 0.4 个是假阳性。它们的家族内相关大多弱于总体相关，例如 `f10_chrono` 总体 ρ = +0.29，家族内只有 +0.05。这说明相当一部分关联来自家族之间的差异，而不是家族内部可迁移的规律。
- **三个优势组之间的差异**（Kruskal–Wallis p < 0.01）：22 个特征满足。在 507 个检验中，偶然情况下约应有 5 个。它们集中在两类：
  - 三动作 0.2 / 0.5 s 时的 glue 与 best-trail 之差；
  - 局部搜索的下降与停滞。

  这些特征彼此高度相关，不是 22 个独立发现。

**有机制意义、但只是相关的观察**（机制假说，未经干预验证）：
- **F− 学得更差时 F− 更慢**：在 F+ 优势组中，F− 学到的子句比 D 大得多（`e02_size_dFm` 中位 +5.6 个文字），F− 优势组则相反（−0.3）。短试跑中“哪个动作学得更好”与最终胜负有弱的同向关系。
- **传播的方向不对称**：在 F− 优势组中，双边传播（`b03_props_lr_top16`）和二元蕴含可达性（`d01_reach_lr_mean`）的正负对数比中位数都接近 0，即正负两侧传播量差不多。D 优势、F+ 优势和全部超时组约为 0.75–1.35；接近组居中，分别为 0 和 0.47。
- **反向等价比例偏低**：F− 优势组的 `c04_inverse_share` 中位 0.07，其他组为 0.13–0.30。

## 5. 编码诊断（H01/H02，工程面板）

- **全局翻转**：静态特征 3,937/3,937 个值精确地取反、取补或互换。但在 512 次冲突时，“翻转公式上的 F+”与“原式上的 F−”只有 30/85 题搜索逐项相同。CaDiCaL 在 forcephase 之外的部分并不对符号对称，所以 F+/F− 的比较不是单纯的“决策符号”比较。
- **重排**：169 个静态特征中 119 个完全不变；其余依赖抽样或处理顺序。0.5 s 试跑的 best-trail 指标在原式与重排公式之间的 ρ 只有 0.61–0.86，带有编号噪声。

## 6. 小结

新观测在机制上更细，比如学习质量的跨动作差、传播方向、相位轨迹与局部搜索，而且都不贵：大多数静态观测只要毫秒级。但它们与“哪个动作更好”的单变量关系仍然很弱，且多半跨家族、而非家族内部的规律。这与 [SELECTION_AND_ABLATION.md](SELECTION_AND_ABLATION.md) 的结论一致：加入这些观测，没有一个观察包在同一读出器下相对 S28 有可证实的增量。

这是“已实施的观测在此面板上没有显示出可用信号”，不是“所有识别方式都不可能”。
