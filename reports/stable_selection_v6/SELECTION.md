# R3：有限的选择实验（8 个登记比较）

所有数字都是 dev 401 的外层 5 折 OOF 结果。

- **设置**：沿用 v5 的家族组折（外层等于 v4 的折，内层 3 折）；成本按 v5 第 5 节模拟，全部观察 CPU 都计入；区间是家族 cluster bootstrap 95%。
- **范围**：这是曝光后的开发评估。
- **其他产出**：生成表格附在后面。逐题 OOF 选择与预测收益在 `results/stable_selection_v6/oof.csv`，增量在 `increments.csv`。

## 1. 比较了什么

| 比较 | 输入 | 读出器 |
| --- | --- | --- |
| P1\|RG、P1\|M05 | S28（只解析，0.04 s） | RG / M05 |
| P2\|RG、P2\|M05 | S28 + 修复后的局部搜索 LS6 | RG / M05 |
| P3\|RG、P3\|M05 | S28 + SATzilla 2024 子集 | RG / M05 |
| R-LS | 6 个局部搜索起点差异特征 | 深度 2 的规则门 |
| R-SYM | 6 个 v5 中有弱信号的结构 / 传播对称特征 | 深度 2 的规则门 |

**读出器**：
- **RG**：v5 的绝对成本差 ridge 加默认回退门。
- **M05**：分别预测每个动作在剩余预算内的解出概率，以及解出时的条件耗时，合成预测 PAR2；只有比同一观察后的 D 好超过 θ 时才偏离。
- **规则门**：只用预先指定的不超过 6 个特征。一个叶子只有当训练支持量 ≥ 15 题、来自 ≥ 3 个家族组、平均收益 > θ 时，才允许偏离。

## 2. 结果：没有一个比较优于始终 D

| 比较 | 相对始终 D | 偏离 F+/F− | 偏离精度 | 正确偏离 / 错误偏离（秒/题） |
| --- | --- | --- | ---: | --- |
| P1\|RG | −0.31% [−1.82, +0.92] | 5/0 | 0.20 | 1.26 / 2.41 |
| P1\|M05 | −0.00% [−0.01, +0.02] | 1/2 | 0.33 | 0.03 / 0.00 |
| P2\|RG | −1.42% [−3.74, +0.40] | 22/12 | 0.15 | 3.56 / 8.13 |
| P2\|M05 | −1.13% [−3.19, +0.35] | 14/9 | 0.22 | 2.29 / 5.75 |
| P3\|RG | −0.62% [−3.40, +2.27] | 35/19 | 0.26 | 7.97 / 8.53 |
| P3\|M05 | −0.77% [−2.35, +0.53] | 6/8 | 0.14 | 1.29 / 2.41 |
| R-LS | −0.62% [−1.57, −0.03] | 5/0 | 0.00 | 0.00 / 1.49 |
| R-SYM | −0.02% [−0.02, −0.01] | 0/0 | — | 0 / 0 |

- **一致性校验**：P1|RG 与 v5 的 S28|RG（−0.3%）一致。
- **最接近 0 的组合**：
  - P1|M05 在 401 题上只偏离 3 次，几乎就是始终 D；
  - R-SYM 在所有折上都没有找到“支持量 ≥ 15、≥ 3 个家族、收益 > θ”的叶子，从不偏离，退化为默认基线。
- **偏离最多的组合 P3|RG**（SATzilla + ridge，偏离 54 次）：
  - 在原 F+ 优势组上每题平均省 4.8 s，在 D 优势组上每题平均多付 8.7 s；
  - 正确偏离省下的时间（7.97 s/题）几乎被错误偏离（8.53 s/题）全部抵消，再扣除 0.78 s 的观察开销；
  - 这是 8 个比较里唯一一个“正确偏离的节省量”接近 v4 / v5 水平的组合，但仍然无法变成净收益。

## 3. 增量与读出器对照

所有配对区间都含 0：

- **新特征对 S28 的增量**（同一读出器）：P2、P3 相对 P1，RG 和 M05 下的配对差均为负（−1.2 到 −4.3 秒/题）。
- **M05 对 RG 的增量**（同一输入）：P1 +1.2、P2 +1.1、P3 −0.6 秒/题。M05 的偏离通常比 RG 更少，错误偏离的损失也更小，但正确偏离的节省同样更少。

按协议的断言规则，**修复后的局部搜索、SATzilla 子集，以及 M05 读出器，都没有显示出增量**。

## 4. 晋级与真实检查

- **晋级**：没有 OOF 净收益为正的候选，所以按协议只晋级最好的 P1|M05，作为“负对照部署”。最终模型为 C = 0.1、θ = 100 s，即只有预测收益超过 100 秒才偏离 D。
- **真实检查**（检查 30 题，折模型）：
  - 动作与离线 30/30 一致；
  - 真实与模拟成本中位差 −0.02 s；
  - wrapper 额外 CPU 中位 0.063 s，在预留的 0.1 s 之内。
  - 最大的差是一题固定 D 运行超时、而 wrapper 中同一 D 搜索在 296 s 解出；另有几题 D 这次比 v4 时期快 7%–11%。这是截止线附近的计时噪声和节点速度差异，所以 R4 让固定运行与 wrapper 交错运行。

## 5. 解释

- **成本上的根本困难**：错误偏离的代价远大于正确偏离的收益。原 D 优势组的错误偏离常常是“D 能解、所选动作超时”，单题就会损失几百秒。
- **结果呈两种形态**：
  - 读出器要么像 P1|M05、R-SYM 那样几乎从不偏离，从而“不亏”；
  - 要么像 P3|RG 那样偏离较多，正确与错误的偏离相互抵消。
- **增加观测的效果**：修复后的局部搜索和成熟 SAT 特征都没有改变这一点，只增加了观察开销和错误偏离。
