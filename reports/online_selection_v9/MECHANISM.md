# v9 R4：把 rephase、强制方向与初始相位分开

日期：2026-10-24（UTC）。协议第 8 节。数据：[mechanism.json](../../results/online_selection_v9/mechanism.json)，样本见 [mechanism_instances.json](../../results/online_selection_v9/mechanism_instances.json)。

## 设计

- **样本**：开发集每格 6 题，先按事后答案分层（各取分割哈希排名靠前的 3 道 SAT 与 3 道 UNSAT，不足时用另一种补齐），共 54 题：28 道 SAT、26 道 UNSAT。答案只用于分层和事后分析，不作为部署输入。
- **配置**：同一批次、同一二进制、seed 0、同一证明政策。选项语义来自固定源码 `third_party/cadical`：`decide.cpp` 中 forcephase 让每次决策使用初始相位，跳过 saved / target 相位；`rephase.cpp` 在 forcephase 时不做 rephase。

  | 配置 | 参数 | 含义 |
  |---|---|---|
  | D | 默认 | rephase 开，saved / target 相位，初始相位 1 |
  | D_R0 | `--rephase=0` | 只关 rephase，仍用 saved / target 相位 |
  | D_P0 | `--phase=0` | 默认机制，初始相位 0 |
  | D_R0_P0 | `--phase=0 --rephase=0` | 初始相位 0，不 rephase，不强制 |
  | F+ / F− | `--forcephase=1 --phase=1/0` | 强制初始方向（也就不再 rephase） |

- **运行**：324 个运行全部完成并独立验证，7.08 核时。

## 解读（只限这三类生成题）

1. **UNSAT 题上 forcephase 的优势，主要来自强制使用固定方向、跳过 saved / target 相位，而不是关闭 rephase。**
   - 只关 rephase 时，UNSAT 题上的效果接近 0：中位 −0.04，12 题快、8 题慢。
   - 在已关 rephase 的基础上再强制方向（F+ 对 D_R0），26 道 UNSAT 题中 24 题明显更快，总量约减半。
   - 随机 3-SAT 上正负方向都有这个效果（F+、F− 对各自的无 rephase 对照都约快 1.5 倍）。
2. **在结构化编码上，强制的方向起决定作用。**
   - 着色与分配题的 UNSAT 上，强制全真（F+）有利，强制全假（F−）不利：着色 UNSAT 上 F− 比 F+ 9 题全慢，总量是 2.3 倍。
   - 这与 v8 符号翻转检查中“F+ / F− 对调”的极性效应一致。
   - 在不强制时，初始相位几乎不影响结果（D_P0 对 D 接近 0），因为 saved 相位很快就覆盖了初始相位。
3. **SAT 题，尤其随机 SAT 题，依赖 rephase 和 saved / target 相位。**
   - 两者分别去掉都显著变慢：rand3 SAT 上只关 rephase 中位慢 2.9 倍；在此基础上再强制，总量是 39 倍。
   - 所以 forcephase 在随机 SAT 题上的巨大损失，是这两部分共同造成的。

## 对 v8 说法的纠正

- **v8 的原话**：v8 [MECHANISM.md](../stratified_v8/MECHANISM.md) 与最终报告写道，随机 3-SAT 上 UNSAT 的优势“来自 forcephase 关闭 rephase 本身”。
- **本节的单因素对照不支持这一说法**：只关 rephase 在 UNSAT 上几乎没有作用；主要作用来自强制决策使用固定方向、不再采用 saved / target 相位。
- **处理**：v8 报告原文保留作为历史记录；正确的表述以本节为准。
- **v8 中仍然成立的部分**：“F+ / F− 的不对称是极性效应”“UNSAT 优势对换号与翻转稳健”，与本节一致。
- **本节没有分开的部分**：saved 与 target 两种相位各自的贡献，因为 `--target=0` 没有单独做对照。这一点保留为假说。
